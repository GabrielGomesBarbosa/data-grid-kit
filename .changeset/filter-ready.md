The filter panel opens on one ready row (no "No filters" text to click past): the row is only shown, and becomes a filter when you change something in it. The Filters button counts only filters that filter (a row with nothing typed is not counted). Popovers move the focus inside once they are positioned (a hidden element cannot take focus, so it never worked in a browser) and the filter panel's value box gets it.
